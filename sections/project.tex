\textbf{WabiSaviArt --- Multi-Vendor E-Commerce Marketplace}
\hfill
\href{https://ahasnat.dev/projects/wabisaviart}{Project Details} \\
A production-ready multi-vendor marketplace connecting buyers and verified makers through role-based dashboards, secure checkout, real-time messaging, and a rich product catalog with variants, media, and seller storytelling features.
\begin{zitemize}
    \item Developed a multi-vendor marketplace supporting buyer, seller, and administrator workflows through fully isolated, role-scoped dashboards.
    \item Built the complete NestJS backend architecture with Prisma ORM, PostgreSQL, Redis caching layer, and Stripe Connect for seller onboarding, product checkout, and automated payouts.
    \item Implemented payment processing, refund workflows, dispute resolution, seller verification with authenticity badges, and marketplace administration features.
    \item Real-time buyer--seller messaging via Socket.IO with presence indicators and message persistence.
    \item S3-compatible media uploads with presigned URL generation for secure, scalable product image management.
    \item Integrated Stripe webhook handler for async payment state reconciliation and payout automation.
\end{zitemize}

\textbf{DovePDF --- Browser-Based PDF Processing Platform}
\hfill
\href{https://ahasnat.dev/projects/dove-pdf}{Live} \textbar{} \href{https://ahasnat.dev/projects/dove-pdf}{Project Details} \\
A privacy-first, web-based PDF toolkit enabling users to edit, annotate, merge, compress, and export PDF files entirely in the browser with client-side processing for instant feedback and zero server-side file exposure.
\begin{zitemize}
    \item Built a full-stack PDF editing platform supporting annotations, signatures, image insertion, page reordering, merging, compression, and export --- all processed client-side via PDF-lib for enhanced privacy.
    \item Offloaded heavy PDF processing to Web Workers to keep the main thread responsive on 50+ page documents; designed pixel-accurate overlay coordinate normalization for correct annotation export across zoom levels.
    \item Architected undo/redo history system, local session persistence for resuming edits without re-upload, and drag-and-drop page reordering with live preview.
    \item Structured as a Turborepo monorepo with tRPC for fully type-safe client--server communication and modular architecture for scalable tool additions.
    \item Integrated Google Ads for monetization without server-side processing overhead; built optimized export pipelines for high-quality document generation.
\end{zitemize}
