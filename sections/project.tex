\textbf{Sarkar Group --- Internal Management System}
\hfill
\href{https://ahasnat.dev/projects/sarkar-group-smd}{More Details}

A production-grade internal management platform for a construction and marine engineering company. Multiple roles — Super Admin, Admin, Project Manager, Engineer, and Client — each operate within a tailored, permission-isolated dashboard covering project lifecycle, equipment tracking, financial approvals, HR applications, media publishing, and real-time notifications.

\begin{zitemize}
    \item Project lifecycle management with engineer assignment, equipment linking, and status tracking.
    \item Equipment request workflow: employee requests → admin approve/reject → auto-assign on approval.
    \item 8 HR application types: leave, resignation, transfer, salary advance, loan, complaint, grievance, expense reimbursement.
    \item Real-time SSE notifications pushed to all relevant users on every workflow event.
\end{zitemize}
